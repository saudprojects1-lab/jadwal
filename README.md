# جدول الضيافة

موقع لعرض جدول الضيافة لأيام الجمعة وتصديره كصور، مع لوحة إدارة لتعديل البنود والأعداد والأشخاص والتواريخ.

الرابط: https://saudprojects1-lab.github.io/jadwal/

## الملفات

| الملف | الوظيفة |
|---|---|
| `index.html` | هيكل الصفحة فقط |
| `data.json` | **كل البيانات**: الأشخاص، البنود، التواريخ، التوزيع، التنبيهات، بصمة كلمة المرور |
| `css/styles.css` | التصميم |
| `js/app.js` | التحميل والعرض والبحث و«جدولي» والتنقل |
| `js/admin.js` | وضع المدير: الدخول، الحفظ، تعديل الخانات، لوحة الإدارة |
| `js/scheduler.js` | قواعد التوزيع وكل عمليات التعديل |
| `js/store.js` | الحالة، التراجع/الإعادة، المسودة المحلية |
| `js/github.js` | قراءة وكتابة `data.json` عبر GitHub API |
| `js/render.js`, `js/export.js`, `js/dates.js`, `js/ui.js`, `js/auth.js` | العرض، تصدير الصور، التواريخ والهجري، النوافذ والتنبيهات، كلمة المرور |

لا توجد خطوة بناء (build). ارفعي الملفات كما هي إلى جذر المستودع على الفرع `main`.

## كيف يعمل الحفظ

- الزوار يقرؤون `data.json` مع منع التخزين المؤقت، فيرون آخر نسخة منشورة.
- المدير يقرأ ويكتب `data.json` مباشرة عبر GitHub API (لا يتأثر بتخزين GitHub Pages المؤقت).
- كل تعديل يُحفظ فوراً كمسودة على الجهاز، ولا تُحذف المسودة إلا بعد نجاح الحفظ.
- إذا حفظ جهاز آخر نسخة أحدث، يظهر خيار «تحميل الأحدث» أو «استبدالها بنسختي» بدل الكتابة فوقها بصمت.

## الدخول كمدير

زر ⚙ أعلى الصفحة، أو أضيفي `#admin` للرابط. كلمة المرور: `123` (تتغير من «الحفظ والإعدادات»). الجهاز يتذكر الدخول حتى تضغطي 🔒 خروج.

لأول مرة: «⚙ الإدارة» ← «الحفظ والإعدادات» ← الصقي رمز الوصول (Fine-grained token بصلاحية **Contents: Read and write** على مستودع `jadwal` فقط). يُحفظ الرمز على الجهاز فقط.

## التشغيل محلياً

```bash
python -m http.server 8000
# ثم افتحي http://localhost:8000
```
(فتح `index.html` مباشرة كملف لا يعمل، لأن المتصفح يمنع قراءة `data.json` من ملف محلي.)
